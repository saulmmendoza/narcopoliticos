Automated Website Mirror

HTTrack  +  GitHub Actions  +  GitHub Pages

🔄 Weekly Sync 📦 Full Assets ⚡ Free Hosting 🔍 Diff Detection

1 · Architecture Overview

Three tools form a simple, zero-cost pipeline:

🌐 narcopoliticos.com
→
🤖 HTTrack (crawl)
→
⚙️ GitHub Actions (cron)
→
📁 gh-pages branch
→
🚀 GitHub Pages
  • HTTrack — CLI tool that recursively downloads a website, rewriting internal links so everything works offline.
  • GitHub Actions — runs the crawl on a cron schedule (Sunday 03:00 UTC), detects whether content changed, and commits only when it did.
  • GitHub Pages — serves the gh-pages branch as a static site at https://<user>.github.io/<repo>/.

3 · GitHub Actions Workflow

Save this as .github/workflows/mirror.yml:

name: Mirror narcopoliticos.com

on:
  schedule:
    - cron: "0 3 * * 0"   # Every Sunday at 03:00 UTC
  workflow_dispatch:        # On-demand manual trigger

permissions:
  contents: write

jobs:
  mirror:
    runs-on: ubuntu-latest
    timeout-minutes: 120

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Install HTTrack
        run: |
          sudo apt-get update -qq
          sudo apt-get install -y --no-install-recommends httrack

      - name: Mirror narcopoliticos.com
        run: |
          mkdir -p site
          httrack "https://narcopoliticos.com" \
            -O "./site" \
            "+*.narcopoliticos.com/*" \
            -v \
            --mirror \
            --depth=10 \
            --max-rate=50000 \
            --connection-per-second=1 \
            --sockets=4 \
            --timeout=30 \
            --retries=3 \
            --robots=0 \
            -A999999999 \
            --near \
            --nowrap \
            -F "Mozilla/5.0 (compatible; HTTrack/3.49-2)" \
            --disable-security-limits

      - name: Assemble deploy directory
        run: |
          mkdir -p deploy
          if [ -d "site/narcopoliticos.com" ]; then
            cp -r site/narcopoliticos.com/. deploy/
          else
            cp -r site/. deploy/
          fi
          cp mirror.html deploy/mirror.html
          rm -f deploy/hts-cache deploy/cookies.txt deploy/hts-log.txt

      # Restore the hash saved by the previous successful run so we can
      # skip deployment when the crawled content has not changed.
      - name: Restore content hash cache
        uses: actions/cache/restore@v4
        with:
          path: deploy_hash.txt
          key: site-hash-${{ github.run_id }}
          restore-keys: |
            site-hash-

      - name: Check for changes
        id: diff
        run: |
          PREV=""
          [ -f deploy_hash.txt ] && PREV=$(cat deploy_hash.txt)
          CURR=$(find deploy -type f | sort | xargs md5sum 2>/dev/null \
                 | md5sum | awk '{print $1}')
          echo "prev=$PREV  curr=$CURR"
          if [ "$PREV" != "$CURR" ]; then
            echo "$CURR" > deploy_hash.txt
            echo "changed=true"  >> "$GITHUB_OUTPUT"
          else
            echo "changed=false" >> "$GITHUB_OUTPUT"
          fi

      - name: Save content hash cache
        if: steps.diff.outputs.changed == 'true'
        uses: actions/cache/save@v4
        with:
          path: deploy_hash.txt
          key: site-hash-${{ github.run_id }}

      - name: Deploy to GitHub Pages
        if: steps.diff.outputs.changed == 'true'
        uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./deploy
          publish_branch: gh-pages
          commit_message: "mirror: update ${{ github.run_number }}"
          force_orphan: false
          enable_jekyll: false

      - name: No changes – skip deploy
        if: steps.diff.outputs.changed == 'false'
        run: echo "Content unchanged."

4 · HTTrack Command Configuration

httrack "https://narcopoliticos.com" \
  -O "./site"                    # Output folder
  "+*.narcopoliticos.com/*"      # Include everything on the domain
  -v                             # Verbose output
  --mirror                       # Full mirror mode (-w)
  --depth=10                     # Max crawl depth
  --max-rate=50000               # Download cap: 50 KB/s (polite)
  --connection-per-second=1      # Max 1 new connection per second
  --sockets=4                    # Parallel connections
  --timeout=30                   # Per-request timeout (seconds)
  --retries=3                    # Retry failed requests 3 times
  --robots=0                     # Ignore robots.txt
  -A999999999                    # Max individual file size (no cap)
  --near                         # Fetch near-linked assets
  --nowrap                       # Don't wrap long log lines
  -F "Mozilla/5.0 ..."           # Custom User-Agent
  --disable-security-limits      # Allow deeper crawls

Include / Exclude Rules

FlagEffect
+*.narcopoliticos.com/*Include all pages & assets on the primary domain
-*.youtube.com/*Exclude embedded YouTube videos
-ad.doubleclick.netExclude ad networks
+*.narcopoliticos.com/*.cssForce-include stylesheets even if cross-domain

Add additional rules between the URL and -O. Rules are evaluated in order; first match wins.

5 · Deployment to GitHub Pages

1

Enable GitHub Pages

Go to Settings → Pages in your repository. Under Source, select Deploy from a branch and choose gh-pages / (root). Click Save.

2

Allow Actions to write

Go to Settings → Actions → General → Workflow permissions and select Read and write permissions. This lets the workflow push to gh-pages.

3

First manual run

In Actions → Mirror narcopoliticos.com, click Run workflow to trigger the first crawl immediately. The gh-pages branch is created automatically.

4

Access your mirror

Once deployed, your mirror is live at:

https://<username>.github.io/<repository-name>/

6 · Optional Enhancements

Diff Detection (already included)

The workflow computes an MD5 fingerprint of every file in the deploy directory and only commits when the fingerprint changes.

Email / Slack Notifications

# Add to the bottom of the workflow job:
- name: Notify on success
  if: steps.diff.outputs.changed == 'true'
  uses: slackapi/slack-github-action@v1
  with:
    payload: '{"text":"Mirror updated: ${{ github.server_url }}/${{ github.repository }}"}'
  env:
    SLACK_WEBHOOK_URL: ${{ secrets.SLACK_WEBHOOK_URL }}

Snapshot / Versioned Archives

# After the Assemble step, add:
- name: Create dated archive
  run: |
    DATE=$(date +%Y-%m-%d)
    tar -czf "snapshot-${DATE}.tar.gz" deploy/
    # Upload as a GitHub release asset or store in a separate branch

Multi-site Mirroring

strategy:
  matrix:
    site:
      - url: "https://narcopoliticos.com"
        name: narcopoliticos
      - url: "https://example.org"
        name: example
# Then reference ${{ matrix.site.url }} and ${{ matrix.site.name }}

7 · Limitations & Risks

⚠ Legal Considerations

Always confirm you have the right to mirror a website. Check the site's robots.txt, Terms of Service, and applicable copyright law before crawling.

RiskImpactMitigation
Dynamic / JS-rendered sites Content may be missing Use --assume=php%html or switch to Playwright-based crawlers
IP blocking / rate limits Crawl fails mid-run Lower --connection-per-second, use residential proxies
Login-gated content Private pages not mirrored Provide session cookies via --cookie flag with GitHub Secrets
Repository size limits Push may fail (>1 GB) Enable Git LFS, or deploy only the diff via rsync to external hosting
GitHub Pages 1 GB limit Deployment may be refused Strip media with -*.mp4 HTTrack exclude rules

8 · Step-by-step Setup Guide

From an empty repository to a fully working automated mirror:

1

Create a new GitHub repository

gh repo create my-mirror --public --clone
cd my-mirror
2

Add the workflow file

mkdir -p .github/workflows
curl -o .github/workflows/mirror.yml \
  https://raw.githubusercontent.com/saulmmendoza/narcopoliticos/main/.github/workflows/mirror.yml

Edit the workflow and replace narcopoliticos.com with your target URL.

3

Add this instructions page

curl -o mirror.html \
  https://raw.githubusercontent.com/saulmmendoza/narcopoliticos/main/mirror.html
4

Commit and push

git add .github/workflows/mirror.yml mirror.html
git commit -m "feat: add automated mirror workflow"
git push origin main
5

Configure repository settings

  • Settings → Actions → General → Workflow permissions → Read and write permissions
  • Settings → Pages → Source → Deploy from a branch → gh-pages / (root)
6

Trigger the first run

gh workflow run mirror.yml

Or click Run workflow in the GitHub Actions UI.

7

Visit your live mirror

https://<username>.github.io/<repo-name>/

The mirror auto-updates every Sunday at 03:00 UTC and only re-deploys when content has changed.

ℹ️ Custom Domain

Add a CNAME file containing your custom domain to the deploy/ directory in the workflow's "Assemble" step (e.g., echo "mirror.yourdomain.com" > deploy/CNAME), then configure a CNAME DNS record pointing to <username>.github.io.
